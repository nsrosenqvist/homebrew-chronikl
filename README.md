# homebrew-chronikl

Homebrew tap for [chronikl](https://github.com/nsrosenqvist/chronikl) — an AI-powered release notes generator.

## Installation

```sh
brew tap nsrosenqvist/chronikl
brew install chronikl
```

Or install in a single command:

```sh
brew install nsrosenqvist/chronikl/chronikl
```

## Updating

```sh
brew update
brew upgrade chronikl
```
